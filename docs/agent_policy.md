## 1. 재검색 상한

| 항목 | 값 | 왜 |
|---|---|---|
| `max_retries` | 2 | 재작성 1회로 못 찾은 표현 차이(리볼빙→일부결제금액이월약정 등)를 한 번 더 시도할 여유는 두되, 근거가 애초에 없는 질문에서 비용·지연이 선형으로 늘지 않게 끊는다 (ADR-004) |
| 상한에 닿으면 | 근거 한계를 밝힌 답변 | 관련 조항은 찾은 상태(insufficient)라 거절하면 오거절이 된다. 확인된 부분만 답하고 `abstain.insufficient` 문구로 한계를 밝힌다. 근거 자체가 없으면(none) 재검색 없이 바로 거절 |
| 재검색 1회 비용 | 약 5,000ms, 약 4,000토큰 | 실측: 40문항 중 12문항(30%)이 재검색했고, 문항당 평균은 입력 11,845 · 출력 551토큰, 8.7원(`make roi`). hybrid 평균 1.3초 → agentic 평균 11.8초이므로 LLM 4회(재작성·필터·판정·답변)와 재검색을 합쳐 10.5초가 늘었다. 재검색 한 바퀴(재작성 + 검색·리랭크 + 판정)는 그중 약 5초, 토큰은 nano 호출 2~3회분 약 4,000으로 어림 |

**측정으로 정할 것**: 상한을 0·2 로 바꿔 `make agentic-sample` 10문항의 답변률·오거절률·평균 시간을 비교한다.
상한을 늘리면 오거절률은 내려가지만 지연과 비용이 오른다. 어디서 멈출지는 취향이
아니라 서비스 수준으로 정한다. 우리가 고른 지점: 상한 2. 문항당 p95 30초 안에서 재검색 2회까지 허용하고, 3회째부터는 오거절률 개선보다 지연 증가가 크다고 본다

## 2. 지연 예산

| 구간 | 예산 | 실측 |
|---|---|---|
| 검색(Dense+BM25+RRF) | 2,000ms | 약 400ms (4회차 hybrid-norerank 평균 690ms 에서 리랭커 제외분. 맥북 M 시리즈) |
| 리랭킹(후보 10개) | 8,000ms | 약 900ms (hybrid 평균 1,311ms − 검색. `results/hybrid.json`) |
| LLM 호출(재작성·필터·판정·답변) + 재검색 | 8,000ms | 약 10,500ms (agentic 평균 11,821ms − hybrid 1,311ms. 재검색한 30% 문항이 평균을 끌어올린다) |
| **전체 p95** | 30,000ms | 22,601ms (agentic, 실제 모델) / hybrid p95 880ms. 예산 안이지만 여유가 7초뿐이다 |

초과하면 무엇을 먼저 버리는가: 재검색 상한을 2→1 로 낮추고, 그래도 넘으면 리랭커 후보를 10→5 로 줄인다
(예: 리랭커 후보 수를 30→15 로. 품질 손해는 4회차 rerank-sweep 기준 MRR 약 1~2%p)

고객이 그대로 읽는 문장이다. 법무·CS 확인을 받는다.

| 상황 | 문구 | 확인자 |

| 근거 없음 | 문서에서 근거를 찾지 못했습니다. 질문을 조금 더 구체적으로 알려주시거나 상담 창구로 문의해 주세요. | CS |
| 근거 부족 | 관련 조항은 찾았지만 질문에 답하기에는 근거가 부족합니다. 확인된 내용만 안내드립니다. | CS |
| 문서 밖(산출방법서 등) | 이 값은 약관·설명서에 없고 산출방법서 등 비공개 문서에 있습니다. 해당 금융회사 확인이 필요합니다. | 법무 |
| 파라미터 없음(빈칸) | 문서의 해당 항목이 비어 있어({field}) 계산할 수 없습니다. 개별 계약서 또는 창구 확인이 필요합니다. | 법무 |
| 개인정보 요구 | 개인의 계좌·잔액 등 개인 금융정보는 이 시스템에서 다루지 않습니다. | 법무·보안 |

## 4. 에스컬레이션

| 트리거 | 어디로 | 응답 시간 |
|---|---|---|
| 민원 · 분쟁 | 소비자보호(민원) 담당 | 1영업일 |
| 소송 · 손해배상 | 법무 담당 | 1영업일 |
| 해지환급금 | 상품 담당(산출방법서 보유) | 2영업일 |
| 보험금 청구 | 보상 담당 | 1영업일 |
| 불완전판매 | 소비자보호 + 준법감시 | 1영업일 |

자동 응답으로 끝내면 안 되는 것: 민원·분쟁·소송·손해배상은 회사의 법적 입장이 되는 말이라 AI 가 답하면 안 되고, 해지환급금은 약관이 아니라 산출방법서 영역이라 숫자를 만들면 틀린 답이 되며, 보험금 청구와 불완전판매는 개인 계약·사실관계 확인이 필요해 근거 문서만으로 판단할 수 없다
